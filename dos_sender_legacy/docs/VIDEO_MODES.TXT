DOSfer V40-L video modes
========================

Only VGA Mode 0Dh / 320x200 remains.

/VIDEO:320_60  (default)
    BIOS VGA mode 0Dh plus custom ~59.94 Hz vertical timing. The memory layout
    stays 320x200 planar with an 8 KiB page stride and two-page display buffer.

    Playback uses an absolute minimum-visibility deadline and flips on the first
    vertical retrace at or after that deadline. Therefore:

        /HOLD:50 -> normally 3 refreshes -> ~50.05 ms

    when QR generation finishes before the deadline.

/VIDEO:320_70
    Unmodified BIOS Mode 0Dh timing at approximately 70 Hz. A 50 ms minimum
    cannot align perfectly to this refresh rate, so the first safe retrace after
    the deadline is used.

Page flipping
-------------

At VGA initialization, BIOS AH=05h is used once to select page 0 and page 1 and
the resulting CRTC start-address values are measured. During the transfer those
measured values are written directly to CRTC registers 0Ch/0Dh at retrace.

This avoids a BIOS interrupt for each QR without assuming a hardcoded CRTC page
address convention.
