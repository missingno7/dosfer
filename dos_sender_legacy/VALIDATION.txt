DOSfer legacy-clean validation
==============================

Scope:
- fixed QR Version 40 (177x177)
- VGA Mode 0Dh / 320x200 only
- VIDEO:320_60 default, VIDEO:320_70 fallback

Checks performed in the refactoring environment:
- sender/config/producer/protocol/VGA/timing/qrcodegen source syntax checked
  with GCC plus small DOS API compatibility stubs
- removed-mode scan: no 640x480, Mode 12h, /SCALE, /V or /VERSION code paths
  remain in src/ or include/
- configuration harness: default V40-L /PAYLOAD:2904 /VIDEO:320_60 validates;
  640_60 is rejected and 320_70 remains accepted
- protocol refactor compared against the pre-cleanup protocol implementation
  for 500 deterministic randomized frames, including plain, whitened and
  pair-whitened payloads: byte-for-byte PASS

Open Watcom is not installed in this environment, so DOSFER.EXE was not rebuilt.
Run build.bat with Open Watcom before testing on DOS/DOSBox/real hardware.
